Broadcaster manifest

The root account authorises the accounts that publish game records. Verifiers accept only records signed by an account authorised before the record's block, so publish this before the server starts broadcasting. It is signed with the root account's active key in Steem Keychain, on this computer: that key never goes to the game server. To revoke every broadcaster (for example after a leaked key), publish an empty list.
